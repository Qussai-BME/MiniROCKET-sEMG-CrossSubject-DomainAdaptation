# Changelog

## 2.0.0

Major revision. Results of v1.0.0 are superseded.

### Corrections
- **CORAL, error 1:** the target features were being re-colored with their own Cholesky factor after alignment. CORAL now transforms the source features only; the target is left untouched.
- **CORAL, error 2:** the whitening/re-coloring matrix was built in the wrong orientation (`Ls^-1 @ Lt` instead of `Ls^-T @ Lt^T`), so source and target covariances were not actually aligned. On synthetic data the Frobenius error dropped from about 285 to about 0.35 after the fix (`tools/audit_coral_synthetic_test.py`).
- Fold counting: the study has **73 held-out-subject folds** (40 + 11 + 22); "365" counts method-fold evaluations (73 x 5 methods).

### Protocol changes
- Canonical MiniROCKET (`sktime`) is the primary extractor; the original hand-written PPV extractor is retained as a labelled comparator.
- Evaluation is explicitly labelled inductive LOSO (`EVALUATION_PARADIGM` stored in every result file).
- Held-out subject data are split at repetition level into an unlabeled calibration part and a disjoint final-test part; adaptation methods see only the calibration part.
- Within-subject baseline redesigned with a repetition-level split (the previous window-level split leaked).
- Feature centering removed from inferential statistics (identical to raw).
- Added balanced accuracy, macro-F1, per-class F1 and confusion matrices to every fold result.
- Five seeds (42, 123, 2024, 7, 999) instead of one.
- DB2 evaluated with the full 49-movement protocol.
- Shared-feature pipeline (`optimized_pipeline.py`): one MiniROCKET fit per fold reused across methods, atomic checkpoints, resumable runs.

### Reporting
- Statistics are computed at subject level on metrics averaged over the five seeds: Friedman with Iman-Davenport correction, two-sided paired Wilcoxon tests with Holm-Sidak adjustment (six contrasts per database and metric), bootstrap 95 % intervals (10,000 resamples) and paired d_z. All tables and figures of the article are generated by the scripts in `paper_reproduction/` (`run_all.py`); the synthetic CORAL verification of Figure 5 / Table S13 is `tools/audit_coral_synthetic_figure5.py`.
- `statistical_utils.holm_sidak_correction` now implements the Holm-Sidak adjustment (previously Holm-Bonferroni).
- Single-seed tables of v1.0.0 and outputs of the removed ablation / diagnostic analyses are no longer shipped.

### Housekeeping
- Added `sktime` and `numba` to the requirements; removed internal logs, caches, checkpoints, duplicate result files and the legacy orchestration scripts from the distribution.
